# Design Documentation

This directory contains UI/UX guidelines, design system, and visual assets for iKampus.

## 🎨 Design Philosophy

iKampus is designed for **Gen Z students** with a focus on:
- ⚡ Speed and simplicity
- 🌙 Dark mode by default
- 📱 Mobile-first experience
- 🎯 Intuitive navigation
- ✨ Visually engaging interface

## 🎨 Color Palette (Draft)

### Primary Colors
- **Primary Blue:** `#2563EB` - Main brand color
- **Primary Dark:** `#1E40AF` - Dark mode accent
- **Primary Light:** `#60A5FA` - Highlights

### Semantic Colors
- **Success:** `#10B981` - Confirmations, success states
- **Warning:** `#F59E0B` - Warnings, important notices
- **Error:** `#EF4444` - Errors, destructive actions
- **Info:** `#3B82F6` - Information, tips

### Neutral Colors
- **Background Dark:** `#0F172A` - Dark mode background
- **Background Light:** `#F8FAFC` - Light mode background

## 📐 Layout Principles

### Mobile-First Grid
- 4-column grid on mobile
- 8-column grid on tablet
- 12-column grid on desktop

### Spacing Scale
- `xs`: 4px
- `sm`: 8px
- `md`: 16px
- `lg`: 24px
- `xl`: 32px
- `2xl`: 48px

## ✨ Key UI Components

### Navigation
- Bottom tab bar (mobile)
- Side drawer for communities
- Top app bar with notifications

- Infinite scroll
- Pull-to-refresh
- Card-based layout
- Quick actions (like, comment, share)

### Messaging
- Chat bubbles
- Typing indicators
- Read receipts
- Message reactions

- Cover photo + avatar

- Activity feed
